# Titanic — описание датасета

Источник: Kaggle — Titanic: Machine Learning from Disaster.

- `train.csv`: 891 строка, целевая переменная `Survived`.
- `test.csv`: 418 строк, целевая переменная в исходном тесте отсутствует.
- Целевая переменная: `Survived` (0 — не выжил, 1 — выжил).
- Основные признаки: PassengerId, Pclass, Name, Sex, Age, SibSp, Parch, Ticket, Fare, Cabin, Embarked.
- В train: 549 пассажиров не выжили (61.6%), 342 выжили (38.4%).

В ноутбуке выполняется дополнительная проверка размеров, типов и пропусков.
