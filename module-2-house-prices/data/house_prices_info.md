# House Prices — информация о данных

Источник: Kaggle, **House Prices: Advanced Regression Techniques**.

- `train.csv`: 1460 строк, содержит целевую переменную `SalePrice`.
- `test.csv`: 1459 строк, без `SalePrice`.
- 79 исходных признаков.
- Цель: прогноз стоимости дома.

Перед запуском notebook скачайте `train.csv` и `test.csv` с Kaggle и положите их в эту папку.
